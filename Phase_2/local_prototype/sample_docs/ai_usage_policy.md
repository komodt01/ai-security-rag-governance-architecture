# Mock AI Acceptable Use Policy

## Purpose

This mock policy defines acceptable and prohibited use of the internal AI assistant.

This document is synthetic and is used only for the local prototype.

## Classification

Internal

## Approved Users

This document may be accessed by authenticated mock users.

Approved roles include:

- General Employee
- Business Analyst
- Engineer
- Security Architect
- IAM Analyst
- Compliance Analyst
- Security Reviewer

## Acceptable Use

Employees may use the AI assistant to:

- Find approved internal guidance
- Summarize mock policy documents
- Ask general questions about security practices
- Locate approved architecture standards
- Review mock governance requirements
- Understand documented AI usage expectations
- Learn which team owns a process or control

## Prohibited Use

Employees must not use the AI assistant to:

- Enter customer data
- Enter employee records
- Enter payment data
- Enter passwords
- Enter API keys
- Enter private keys
- Enter production secrets
- Upload real company confidential documents
- Request restricted incident response details without authorization
- Ask the assistant to bypass access controls
- Ask the assistant to ignore system instructions
- Use AI-generated output as final legal, compliance, or access approval

## Human Review Requirements

Human review is required when a request involves:

- Security exceptions
- Access approval
- Privileged access
- Compliance interpretation
- Legal interpretation
- Incident response decisions
- Production-impacting recommendations
- Restricted data
- Regulated data

## Advisory-Only Statement

The AI assistant provides advisory guidance based on approved documents.

It does not approve access, approve exceptions, make final compliance decisions, or authorize production changes.

## Security Reminder

Users are responsible for protecting sensitive information.

If a user accidentally enters a secret, credential, or regulated data into the assistant, the event should be reported through the appropriate incident response process.
